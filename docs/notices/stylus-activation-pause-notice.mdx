The [Arbitrum Security Council](https://docs.arbitrum.foundation/concepts/security-council) has temporarily paused new <a data-quicklook-from="stylus">Stylus</a> contract <a data-quicklook-from="activation">activations</a> on <a data-quicklook-from="arbitrum-one">Arbitrum One</a> and <a data-quicklook-from="arbitrum-nova">Arbitrum Nova</a> as a preventive security measure. No attack has occurred. No user funds are affected.

<VanillaAdmonition type="warning" title="What this means for you">

- You cannot activate new or expired Stylus contracts on Arbitrum One or Arbitrum Nova while the pause is in effect.
- Already activated Stylus contracts keep running. Calling them remains permissionless.
- Solidity and EVM contract deployment and execution are unaffected.

</VanillaAdmonition>

Read the Security Council action: **[SC action post]**

## What is paused

The pause applies to the activation step only. Activation is the step that makes a Stylus contract callable. To learn how deployment and activation work, refer to [Activation](/stylus/concepts/activation.mdx).

Contracts activated before the pause are not affected. Users and other contracts can call them as before.

## Why the Security Council paused activations

Known Stylus findings concern chain liveness, that is, denial of service. To date, no known or reported Stylus bug has affected or put user funds at risk.

These findings involve hand-crafted <a data-quicklook-from="wasm">WASM</a> that falls outside the code the standard Stylus compiler produces. Ordinary Stylus contracts built with the standard compiler toolchain are not a current concern.

AI-assisted tooling is making it easier to discover and construct adversarial programs that exercise unusual parts of the WASM execution surface. The pause reduces exposure to these vectors while the evaluation continues.

## What comes next

We remain confident in Stylus, which lets chain owners customize their networks and developers optimize key contracts. The Arbitrum Foundation will work with the <a data-quicklook-from="arbitrum-dao">ArbitrumDAO</a> on next steps for reopening activations in a way that preserves these uses while restricting hand-crafted WASM programs.
