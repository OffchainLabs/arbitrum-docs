The count of blocks an [edge](/intro/glossary#edge) has stayed unrivaled. The protocol measures time in blocks of the first non-Arbitrum ancestor chain — Ethereum blocks for L2 chains, and for L3 chains that settle to an Arbitrum chain. An edge's timer stops when a [rival](/intro/glossary#rival) edge appears onchain. Two edges are rivals when they agree on some prefix of a computation from the same start state, but disagree on the rest of it. The protocol confirms an [assertion](/intro/glossary#assertion) once the timer of its unrivaled edge reaches the [challenge period](/intro/glossary#challenge-period).
