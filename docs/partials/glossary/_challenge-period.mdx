title: Challenge Period
key: challenge-period
titleforSort: Challenge Period
---

The window over which anyone can challenge an [assertion](/intro/glossary#assertion), after which the assertion can be confirmed. On Arbitrum One it is [6.4 days](/arbitrum-essentials/reference/chain-params.mdx). The [Arbitrum DAO](/intro/glossary#arbitrum-dao) can configure this value. A [BoLD](/intro/glossary#bold) challenge adds at most one more challenge period before an assertion confirms.
