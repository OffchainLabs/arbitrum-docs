Locking WETH in the [Rollup contract](/intro/glossary#rollup-contract) to gain the right to post [assertions](/intro/glossary#assertion). A party joins the validator set by posting one large assertion bond. Later assertions from the same party need no further bond, because the protocol treats each [bonder](/intro/glossary#bonder) as bonded to their latest assertion. Opening a sub-challenge needs a smaller [challenge bond](/intro/glossary#challenge-bond). Bonded funds are lost if a competing assertion is confirmed, and can be withdrawn once the bonded assertion is confirmed.
