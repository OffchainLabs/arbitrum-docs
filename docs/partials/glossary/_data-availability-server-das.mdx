---
title: Data Availability Server (DAS)
key: data-availability-server-das
titleforSort: Data Availability Server (DAS)
---

The server software each member of a [Data Availability Committee (DAC)](/intro/glossary#data-availability-committee-dac) runs to store [batch](/intro/glossary#batch) data and serve it on demand. On an [AnyTrust](/intro/glossary#arbitrum-anytrust-protocol) chain the [sequencer](/intro/glossary#sequencer) sends batch data to the committee's DAS instances, which sign and return a [Data Availability Certificate](/intro/glossary#data-availability-certificate). Nitro ships `anytrustserver` for running a DAS.
