The [BoLD](/intro/glossary#bold) smart contract on the [parent chain](/intro/glossary#parent-chain) that starts challenges on [assertions](/intro/glossary#assertion) and lets anyone join a challenge without permission. It holds the entry points for making challenge moves, opening [edges](/intro/glossary#edge), creating sub-challenges, and confirming challenges.
