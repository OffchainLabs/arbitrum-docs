Deprecated web application built by [Offchain Labs](/intro/glossary#offchain-labs) for developers and users to debug Arbitrum transactions; i.e., executing or checking the status of [Cross-chain messages](/intro/glossary#crosschain-message). It has been replaced by the [Retryable Tickets tool](https://portal.arbitrum.io/build/retryables) and the [bridge transaction history](https://portal.arbitrum.io/bridge?tab=tx_history).
