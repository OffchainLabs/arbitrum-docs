Nitro's default [state scheme](/intro/glossary#state-scheme), which stores the state trie keyed by node hash. HashDB supports block validation, so a node running the block validator must use it. Unlike [PathDB](/intro/glossary#pathdb), HashDB [prunes](/intro/glossary#state-pruning) manually and offline through `--init.prune`: the node stops serving RPC requests until the prune finishes.
