The set of [parent chain](/intro/glossary#parent-chain) contracts that implement a miniature [WASM](/intro/glossary#wasm) VM, often shortened to `OSP`. The VM executes a [one step proof](/intro/glossary#one-step-proof) of the [child chain](/intro/glossary#child-chain) [state transition function](/intro/glossary#state-transition-function), which settles a challenge. It is written in Solidity. [BoLD](/intro/glossary#bold) needs no changes to these contracts.
