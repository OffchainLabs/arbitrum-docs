title: 'MultiVM'
---

MultiVM refers to Arbitrum's ability to support multiple virtual machines (VMs). Specifically, Arbitrum <Term id="stylus">Stylus</Term> introduces a WebAssembly (<Term id="wasm">WASM</Term>)-based virtual machine alongside the traditional Ethereum Virtual Machine (EVM). This means developers can write <Term id="smart-contract">smart contracts</Term> in languages like Rust, C, or C++ (compiled to WASM) or continue using Solidity for the EVM, and both types of contracts can interact on the same chain. This approach preserves EVM compatibility while enabling more efficient execution and access to a broader set of programming languages and libraries. Learn more about [Stylus](/docs/stylus/gentle-introduction) and language support.
