title: 'Data Availability Server (DAS)'
---

The server software each member of a [Data Availability Committee (DAC)](/glossary#data-availability-committee-dac) runs to store [batch](/glossary#batch) data and serve it on demand. On an [AnyTrust](/glossary#arbitrum-anytrust-protocol) chain the [sequencer](/glossary#sequencer) sends batch data to the committee's DAS instances, which sign and return a [Data Availability Certificate](/glossary#data-availability-certificate). Nitro ships `anytrustserver` for running a DAS.
