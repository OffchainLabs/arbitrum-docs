title: 'Data Availability Server (DAS)'
---

The server software each member of a [Data Availability Committee (DAC)](/docs/glossary#data-availability-committee-dac) runs to store [batch](/docs/glossary#batch) data and serve it on demand. On an [AnyTrust](/docs/glossary#arbitrum-anytrust-protocol) chain the [sequencer](/docs/glossary#sequencer) sends batch data to the committee's DAS instances, which sign and return a [Data Availability Certificate](/docs/glossary#data-availability-certificate). Nitro ships `anytrustserver` for running a DAS.
