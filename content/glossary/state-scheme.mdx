id: state-scheme
title: 'State Scheme'
---

The layout Nitro uses to store its state trie on disk, selected with `--execution.caching.state-scheme`. Nitro supports two: [HashDB](/docs/glossary#hashdb) (the default) and [PathDB](/docs/glossary#pathdb). The two are not interchangeable — a node can only start from a [database snapshot](/docs/glossary#database-snapshot) built with the same state scheme, so switching means re-initializing the database.
