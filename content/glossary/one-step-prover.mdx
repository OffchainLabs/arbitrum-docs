id: one-step-prover
title: 'OneStepProver'
---

The set of [parent chain](/glossary#parent-chain) contracts that implement a miniature [WASM](/glossary#wasm) VM, often shortened to OSP. The VM executes a [one-step proof](/glossary#one-step-proof) of the [child chain](/glossary#child-chain) [state transition function](/glossary#state-transition-function), which settles a challenge. It is written in Solidity. [BoLD](/glossary#bold) needs no changes to these contracts.
