id: one-step-prover
title: 'OneStepProver'
---

The set of [parent chain](/docs/glossary#parent-chain) contracts that implement a miniature [WASM](/docs/glossary#wasm) VM, often shortened to OSP. The VM executes a [one-step proof](/docs/glossary#one-step-proof) of the [child chain](/docs/glossary#child-chain) [state transition function](/docs/glossary#state-transition-function), which settles a challenge. It is written in Solidity. [BoLD](/docs/glossary#bold) needs no changes to these contracts.
