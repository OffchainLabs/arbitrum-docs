## Third-party RPC providers

You can also connect to public Arbitrum chains through many of the node providers that you use on Ethereum.

<Callout type="info" title="Add your project to this list">

To add your project to this list and to the [Arbitrum portal](https://portal.arbitrum.io/one), complete the [portal application form]({var:portalApplicationForm}).

</Callout>

<Callout type="info" title="Get support for Nova third-party tools">

To request support for a Nova third-party tool, complete the [Nova support form](https://docs.google.com/forms/d/e/1FAIpQLSfL1SlycJDyeRQJg-izdFZgN0eqLLAuzHkOr4TIEAZlcuBfSg/viewform).

</Callout>

### Compare provider latency

To compare the live latency of the public Arbitrum endpoints that need no API key, use the [OpenChainBench Arbitrum RPC benchmark](https://openchainbench.com/benchmarks/arbitrum-rpc). OpenChainBench probes each endpoint every minute from three regions. It publishes the p50, p95, and p99 latency under an open methodology and the CC BY 4.0 license.
