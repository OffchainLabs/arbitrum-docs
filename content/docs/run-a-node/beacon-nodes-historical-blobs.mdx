<Term id="layer-2-l2">Layer 2</Term> network operators must connect to an Ethereum beacon chain node with historical <Term id="blob">blob</Term> data to ensure proper functioning of the <Term id="arbitrum-nitro">Nitro</Term> node software, or risk failure in fetching blob data.

If you don't run your own beacon node, see [Ethereum beacon chain RPC providers](/docs/run-a-node/l1-ethereum-beacon-chain-rpc-providers) for a curated list of third-party providers and their historical-blob support status.

## Impacted audiences

Required action will be required from: RPC nodes, <Term id="arbitrum-one">Arbitrum One</Term>/<Term id="arbitrum-nova">Nova</Term> node operators, <Term id="arbitrum-chain">Arbitrum chain</Term> node operators

#### If you run a Nitro node and use an external L1 Ethereum beacon chain RPC URL

- Confirm that your external L1 beacon chain RPC provider has configured their L1 beacon chain node to subscribe to all subnets.

#### If your external L1 beacon chain RPC doesn't subscribe to all subnets:

- Switch to a provider that does.

#### If you run a Nitro node and operate your own L1 Ethereum beacon chain node:

- Add the new flag (refer to [specific client flags](#specific-client-flags)) to your beacon node's configuration.

<VanillaAdmonition type="info" title="Note">

Ensure that the external L1 beacon chain RPC provider you're using subscribes to all subnets.

</VanillaAdmonition>

## L1 beacon chain node flags

### Prysm Consensus Layer clients

Prysm nodes have a new beacon node flag `--subscribe-all-data-subnets` that needs to be added to P2P options. Refer to the [Prysm command-line options documentation](https://prysm.offchainlabs.com/docs/configure-prysm/parameters/) for configuration details.

This flag is available as of Prysm v6.1.0. We recommend upgrading to the [latest stable Prysm releases](https://github.com/OffchainLabs/prysm/releases) to ensure you have the most recent features and security updates.

### Other Consensus Layer clients

Other Consensus Layer nodes also have flags to ensure they sync data from across all subnets.
